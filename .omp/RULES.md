# TuxedoSQL — Project Rules

Hard requirements that apply in every session:

- NEVER manually edit `frontend/bindings/` — it is regenerated by `wails3 generate bindings`.
- NEVER call other services from a service — services are independent silos.
- NEVER import `internal/` from `pkg/` — enforced by the Go toolchain.
- NEVER commit `frontend/dist/` or `bin/` — excluded in `.gitignore`.
- NEVER use raw SQL string interpolation — parameterize with `?` + whitelist columns.
- NEVER hardcode a single driver — use `conn.Driver` to resolve at connection time.
- NEVER call `Schema()` without `conn` — the signature is `Schema(conn *model.Connection)`.
